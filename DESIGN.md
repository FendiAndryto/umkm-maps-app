# DESIGN SYSTEM - UMKM PROMOTION APP

## Design Direction
Gunakan style modern, clean, minimalis, dan professional.
UI harus terasa ringan, premium, dan nyaman dipakai.
Hindari tampilan jadul, terlalu ramai, atau warna norak.

---

# Core Design Principles

- Clean spacing
- Rounded modern components
- Soft shadow
- Minimal border
- Smooth animation
- Consistent padding & margin
- Fokus ke visual produk UMKM
- Mobile-first design
- Responsive web layout
- Simple navigation
- Jangan terlalu banyak warna
